# Path of Science

Сайт наукової спільноти студентів і молодих дослідників Path of Science: події, конференції, партнери та форма заявки.

Живий сайт: https://path-of-science.vercel.app

## Як влаштовано

- `index.html` — односторінковий сайт без збірки: розмітка, стилі та скрипти в одному файлі.
- `apps-script/Code.gs` — приймач заявок на Google Apps Script. Заявка з форми стає рядком у Google Таблиці й повідомленням у Telegram-групі організаторів.
- `og.png` — картинка для попереднього перегляду посилання в месенджерах.

Деплой на Vercel, кожен пуш у `main` викочується автоматично.

## Заявки

Токен бота, ID групи й таблиці в репозиторії не зберігаються. Вони вписані лише в самому проєкті Apps Script, тут у `Code.gs` стоять заглушки.

Щоб підняти свій приймач: створити проєкт Apps Script, вставити `Code.gs`, заповнити три константи зверху, розгорнути як веб-застосунок і вписати його адресу у форму в `index.html`.
